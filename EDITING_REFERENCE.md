# Editing reference

This Google Flow short uses the editing language of Alex’s reel as its starting point:

- **Creator:** Alex / [@nocodealex](https://www.instagram.com/nocodealex/)
- **Reference reel:** [“Own a full AI agency for $0”](https://www.instagram.com/nocodealex/reel/Dc4cu6cySSA/)
- **Role:** Visual and editing inspiration only—not a factual source for the Google Flow script.

## What inspired this edit

- Warm cream background with generous empty space in the lower third.
- A progress rail across the top that advances with each story beat.
- A white title pill overlapping a large rounded visual card.
- Two-line, uppercase headlines with black and orange emphasis.
- Compact illustrated scenes that change quickly with the narration.
- Serif orange captions revealed word by word.
- Fast pacing, clear visual hierarchy, and one main idea per beat.

The HyperFrames implementation in this repository adapts those patterns for the Google Flow topic. It is a team learning example, not a frame-for-frame copy.

When the style changes, add each meaningful reference here with its original creator, direct URL, and the exact editing choices it influenced. This keeps visual inspiration clear as the team experiments with more styles.
