# References and attribution

## Creative reference

- [Jack Roberts — “Steal the loop that 10X'd Claude Design”](https://www.instagram.com/p/DdDJAbFFazu/)

The reference was reviewed for its public-facing topic and editorial structure. It inspired the use of:

- A bold black-and-orange hook.
- Alternating light and dark slides.
- One clear lesson per page.
- A problem → critics → loop → takeaway narrative.
- A creator portrait as a personal anchor.

No reference images, video, or copied slide artwork are stored in this repository. This keeps attribution clear and avoids redistributing another creator's media. The carousel copy, diagrams, portrait treatment, and CCM Field Notes visual system are original.

## Topic source note

The Instagram reference introduced the high-level idea of separating creation from review with multiple critics. This example presents that topic as a practical three-check workflow: brief coverage, design-system compliance, and rendered visual quality. It should be treated as a workflow explanation, not as a claim that any specific model or process guarantees a literal 10× improvement.
