## Patterns measured from the wider internal vault

The internal Instagram shelf contains examples ranging from 3 to 20 slides, with 7–8 the most common useful range. The portable lessons are:

1. **Cover / hook:** stop the thumb with one promise. Keep the core hook under ten words when possible.
2. **Problem:** name the cost, misconception, or old way before teaching the solution.
3. **One named idea per slide:** a tool, step, critic, mistake, or rule should own the page.
4. **Visual proof:** diagrams, screenshots, or a creator portrait should explain—not decorate.
5. **Final save:** give a concrete reason to save, such as retaining commands, a checklist, or a repeatable workflow.

Three dependable story shapes:

| Shape | Suggested sequence | Best for |
| --- | --- | --- |
| Contrarian workflow | Hook → failure → 3 steps → loop → takeaway | Teaching a better process |
| Tool roundup | Hook → one tool per slide → comparison → save/install CTA | Concrete resources |
| Build breakdown | Finished result → problem → research → build → proof → checklist → CTA | Showing how something was made |

These patterns are summarized rather than republishing third-party screenshots whose redistribution rights are unclear. Public references should be linked and attributed; only media with known publishing rights belongs in this repository.
