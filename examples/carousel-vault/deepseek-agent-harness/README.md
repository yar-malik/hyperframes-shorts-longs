# DeepSeek agent-harness carousel

This is a finished six-slide Instagram carousel from Yar Malik's content vault and the visual shown in the screenshot supplied with this repository update.

**Published post:** [DeepSeek just opened the agent loop](https://www.instagram.com/p/DdL814LjkIE/?img_index=1)

![Six-slide contact sheet](carousel-preview.png)

## What to study

- **Cover hierarchy:** one oversized product word, a two-line promise, then a creator portrait and compact system diagram.
- **Restricted palette:** black and warm white do most of the work; electric blue creates depth and pale yellow carries the hook.
- **Portrait as narrator:** the creator changes position and gesture to direct attention instead of appearing as the same repeated cutout.
- **Different composition per slide:** box, product UI, node diagram, process strip, and radial loop keep the swipe sequence moving.
- **Consistent shell:** the field-guide label, thin rounded frame, page number, and bottom action rail make varied pages feel like one set.
- **Texture:** grain, rough cutouts, paper edges, and glow turn a technical subject into an editorial object.

## Reconstructed prompt

The original historical prompt was not stored with this vault item. This reconstruction captures the visible design decisions without pretending to be the exact original:

```text
Create a six-slide 1080×1350 editorial Instagram carousel about DeepSeek
opening the coding-agent loop. Use my authorized black-and-white portrait as
the recurring narrator.

Art direction: an underground technology field guide—near-black paper,
electric cobalt-blue glow and torn-paper shapes, pale-yellow condensed serif
headlines, off-white diagrams, photocopy grain, thin rounded frames, small
monospace labels, and a bottom action rail on every slide.

Sequence:
1. DeepSeek just opened the agent loop — local, extensible, yours.
2. Most coding agents are locked boxes — model, tools, inner loop.
3. The harness changes everything — run local, choose a model, audit tools.
4. Snap in new abilities — show a plugin network.
5. It builds its own tools — write, test, install.
6. Your coding agent can evolve itself — local, open, extensible.

Make every slide compositionally distinct while preserving the same masthead,
frame, page numbering, texture, and footer rail. Keep the portrait crop clean,
headlines readable at thumbnail size, and diagrams legible on a phone. Export
numbered PNGs and one contact sheet. Do not invent factual claims; flag any
statement that needs a source.
```
